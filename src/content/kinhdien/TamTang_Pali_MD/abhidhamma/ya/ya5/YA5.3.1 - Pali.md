# 5 Saccayamaka

# 5.3 Pariññāvāra

# 5.3.1. Paccuppannavāra

**ya5.3.1:1.1** Yo dukkhasaccaṁ parijānāti so samudayasaccaṁ pajahatīti? Āmantā.

**ya5.3.1:2.1** Yo vā pana samudayasaccaṁ pajahati so dukkhasaccaṁ parijānātīti? Āmantā.

**ya5.3.1:3.1** Yo dukkhasaccaṁ na parijānāti so samudayasaccaṁ nappajahatīti? Āmantā.

**ya5.3.1:4.1** Yo vā pana …pe… ? Āmantā.
