# Paṭṭhānapakaraṇa

# Dhammapaccanīya (2), Dukapaṭṭhānapāḷi (2)

# 8.32. Oghadukādi

**patthana8.32:1.1** Nooghaṁ dhammaṁ paṭicca …pe… noyogaṁ dhammaṁ paṭicca …pe…. (Oghagocchakayogagocchakesu āmasanaṁ āsavagocchake āmasanasadisaṁ.)

**patthana8.32:2.1** Nonīvaraṇaṁ dhammaṁ paṭicca …pe…. (Nīvaraṇagocchake āmasanaṁ saññojanagocchake āmasanasadisaṁ.)

**patthana8.32:3.1** Nīvaraṇagocchakaṁ niṭṭhitaṁ.
