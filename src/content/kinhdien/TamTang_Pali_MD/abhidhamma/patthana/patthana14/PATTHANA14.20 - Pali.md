# Paṭṭhānapakaraṇa

# Dhammānulomapaccanīya (3), Dukapaṭṭhānapāḷi (2)

# 14.20. Parāmāsaduka

**patthana14.20:1.1** Parāmāsaṁ dhammaṁ paṭicca noparāmāso dhammo uppajjati hetupaccayā.

**patthana14.20:2.1** Hetuyā pañca …pe… vipāke ekaṁ …pe… avigate pañca. (Āsavagocchakasadisaṁ.)
