# Saṁyutta Nikāya 35.183–185

# 17. Saṭṭhipeyyālavagga

# Bāhirānattachandādisutta

**sn35.183-185:1.1** “Yo, bhikkhave, anattā, tatra vo chando pahātabbo, rāgo pahātabbo, chandarāgo pahātabbo.

**sn35.183-185:1.2** Ko ca, bhikkhave, anattā?

**sn35.183-185:1.3** Rūpā, bhikkhave, anattā; tatra vo chando pahātabbo, rāgo pahātabbo, chandarāgo pahātabbo.

**sn35.183-185:1.4** Saddā …

**sn35.183-185:1.5** gandhā …

**sn35.183-185:1.6** rasā …

**sn35.183-185:1.7** phoṭṭhabbā …

**sn35.183-185:1.8** dhammā anattā; tatra vo chando pahātabbo, rāgo pahātabbo, chandarāgo pahātabbo.

**sn35.183-185:1.9** Yo, bhikkhave, anattā tatra vo chando pahātabbo, rāgo pahātabbo, chandarāgo pahātabbo”ti.
