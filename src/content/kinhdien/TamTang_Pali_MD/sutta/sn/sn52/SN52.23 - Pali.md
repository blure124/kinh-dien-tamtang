# Saṁyutta Nikāya 52.23

# 2. Dutiyavagga

# Dibbacakkhusutta

**sn52.23:1.1** “Imesañca panāhaṁ, āvuso, catunnaṁ satipaṭṭhānānaṁ bhāvitattā bahulīkatattā dibbena cakkhunā visuddhena atikkantamānusakena satte passāmi cavamāne upapajjamāne …pe… iti dibbena cakkhunā visuddhena atikkantamānusakena yathākammūpage satte pajānāmī”ti.

**sn52.23:1.2** Terasamaṁ.
