# Saṁyutta Nikāya 55.29

# 3. Saraṇānivagga

# Dutiyabhayaverūpasantasutta

**sn55.29:1.1** Sāvatthinidānaṁ …pe…

**sn55.29:1.2** “yato kho, bhikkhave, ariyasāvakassa imāni pañca bhayāni verāni vūpasantāni honti, imehi catūhi sotāpattiyaṅgehi samannāgato hoti, ayañcassa ariyo ñāyo paññāya sudiṭṭho hoti suppaṭividdho; so ākaṅkhamāno attanāva attānaṁ byākareyya:

**sn55.29:1.3** ‘khīṇanirayomhi khīṇatiracchānayoni khīṇapettivisayo khīṇāpāyaduggativinipāto; sotāpannohamasmi avinipātadhammo niyato sambodhiparāyaṇo’”ti.

**sn55.29:1.4** Navamaṁ.
