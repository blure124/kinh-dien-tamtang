# Theragāthā 2.28

# Dukanipāta

# Tatiyavagga

# Bharatattheragāthā

**thag2.28:1.1** “Ehi nandaka gacchāma,

**thag2.28:1.2** upajjhāyassa santikaṁ;

**thag2.28:1.3** Sīhanādaṁ nadissāma,

**thag2.28:1.4** buddhaseṭṭhassa sammukhā.

**thag2.28:2.1** Yāya no anukampāya,

**thag2.28:2.2** amhe pabbājayī muni;

**thag2.28:2.3** So no attho anuppatto,

**thag2.28:2.4** sabbasaṁyojanakkhayo”ti.

**thag2.28:2.5** … Bharato thero ….
