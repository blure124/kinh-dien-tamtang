# Theragāthā 2.5

# Dukanipāta

# Paṭhamavagga

# Ajinattheragāthā

**thag2.5:1.1** “Api ce hoti tevijjo,

**thag2.5:1.2** maccuhāyī anāsavo;

**thag2.5:1.3** Appaññātoti naṁ bālā,

**thag2.5:1.4** avajānanti ajānatā.

**thag2.5:2.1** Yo ca kho annapānassa,

**thag2.5:2.2** lābhī hotidha puggalo;

**thag2.5:2.3** Pāpadhammopi ce hoti,

**thag2.5:2.4** so nesaṁ hoti sakkato”ti.

**thag2.5:2.5** … Ajino thero ….
