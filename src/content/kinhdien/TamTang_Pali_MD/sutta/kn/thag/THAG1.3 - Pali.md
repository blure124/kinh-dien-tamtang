# Theragāthā 1.3

# Ekakanipāta

# Paṭhamavagga

# Kaṅkhārevatattheragāthā

**thag1.3:1.1** “Paññaṁ imaṁ passa tathāgatānaṁ,

**thag1.3:1.2** Aggi yathā pajjalito nisīthe;

**thag1.3:1.3** Ālokadā cakkhudadā bhavanti,

**thag1.3:1.4** Ye āgatānaṁ vinayanti kaṅkhan”ti.

**thag1.3:1.5** Itthaṁ sudaṁ āyasmā kaṅkhārevato thero gāthaṁ abhāsitthāti.
