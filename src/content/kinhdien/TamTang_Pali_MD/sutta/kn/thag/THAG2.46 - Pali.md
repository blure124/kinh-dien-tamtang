# Theragāthā 2.46

# Dukanipāta

# Pañcamavagga

# Cūḷakattheragāthā

**thag2.46:1.1** “Nadanti morā susikhā supekhuṇā,

**thag2.46:1.2** Sunīlagīvā sumukhā sugajjino;

**thag2.46:1.3** Susaddalā cāpi mahāmahī ayaṁ,

**thag2.46:1.4** Subyāpitambu suvalāhakaṁ nabhaṁ.

**thag2.46:2.1** Sukallarūpo sumanassa jhāyataṁ,

**thag2.46:2.2** Sunikkamo sādhu subuddhasāsane;

**thag2.46:2.3** Susukkasukkaṁ nipuṇaṁ sududdasaṁ,

**thag2.46:2.4** Phusāhi taṁ uttamamaccutaṁ padan”ti.

**thag2.46:2.5** … Cūḷako thero ….
