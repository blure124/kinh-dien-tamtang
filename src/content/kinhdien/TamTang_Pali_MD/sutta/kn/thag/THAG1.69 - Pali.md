# Theragāthā 1.69

# Ekakanipāta

# Sattamavagga

# Channattheragāthā

**thag1.69:1.1** “Sutvāna dhammaṁ mahato mahārasaṁ,

**thag1.69:1.2** Sabbaññutaññāṇavarena desitaṁ;

**thag1.69:1.3** Maggaṁ papajjiṁ amatassa pattiyā,

**thag1.69:1.4** So yogakkhemassa pathassa kovido”ti.

**thag1.69:1.5** … Channo thero ….
