# Aṅguttara Nikāya 4.226

# 23. Duccaritavagga

# Dutiyamaggasutta

**an4.226:1.1** …pe… Micchāājīvo hoti, micchāvāyāmo hoti, micchāsati hoti, micchāsamādhi hoti …pe… sammāājīvo hoti, sammāvāyāmo hoti, sammāsati hoti, sammāsamādhi hoti …pe….

**an4.226:1.2** Chaṭṭhaṁ.
