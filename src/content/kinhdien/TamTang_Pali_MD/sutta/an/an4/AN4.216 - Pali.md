# Aṅguttara Nikāya 4.216

# 22. Parisāvagga

# Dutiyamaggasutta

**an4.216:1.1** …pe… Micchāājīvo hoti, micchāvāyāmo hoti, micchāsati hoti, micchāsamādhi hoti …pe… sammāājīvo hoti, sammāvāyāmo hoti, sammāsati hoti, sammāsamādhi hoti.

**an4.216:1.2** Chaṭṭhaṁ.
