# Aṅguttara Nikāya 4.215

# 22. Parisāvagga

# Paṭhamamaggasutta

**an4.215:1.1** …pe… Micchādiṭṭhiko hoti, micchāsaṅkappo hoti, micchāvāco hoti, micchākammanto hoti …pe… sammādiṭṭhiko hoti, sammāsaṅkappo hoti, sammāvāco hoti, sammākammanto hoti.

**an4.215:1.2** Pañcamaṁ.
