# Aṅguttara Nikāya 9.32

# 4. Mahāvagga

# Anupubbavihārasutta

**an9.32:1.1** “Navayime, bhikkhave, anupubbavihārā.

**an9.32:1.2** Katame nava?

**an9.32:1.3** Paṭhamaṁ jhānaṁ, dutiyaṁ jhānaṁ, tatiyaṁ jhānaṁ, catutthaṁ jhānaṁ, ākāsānañcāyatanaṁ, viññāṇañcāyatanaṁ, ākiñcaññāyatanaṁ, nevasaññānāsaññāyatanaṁ, saññāvedayitanirodho—

**an9.32:1.4** ime kho, bhikkhave, nava anupubbavihārā”ti.

**an9.32:1.5** Paṭhamaṁ.
