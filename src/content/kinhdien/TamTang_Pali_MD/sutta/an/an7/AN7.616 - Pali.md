# Aṅguttara Nikāya 7

# 11. Rāgapeyyāla

# ~

**an7.616:1.1** “Rāgassa, bhikkhave, abhiññāya satta dhammā bhāvetabbā.

**an7.616:1.2** Katame satta?

**an7.616:1.3** Aniccasaññā, anattasaññā, asubhasaññā, ādīnavasaññā, pahānasaññā, virāgasaññā, nirodhasaññā—

**an7.616:1.4** rāgassa, bhikkhave, abhiññāya ime satta dhammā bhāvetabbā”ti.
