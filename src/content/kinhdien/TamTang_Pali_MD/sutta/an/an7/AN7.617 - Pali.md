# Aṅguttara Nikāya 7

# 11. Rāgapeyyāla

# ~

**an7.617:1.1** “Rāgassa, bhikkhave, abhiññāya satta dhammā bhāvetabbā.

**an7.617:1.2** Katame satta?

**an7.617:1.3** Asubhasaññā, maraṇasaññā, āhāre paṭikūlasaññā, sabbaloke anabhiratasaññā, aniccasaññā, anicce dukkhasaññā, dukkhe anattasaññā—

**an7.617:1.4** rāgassa, bhikkhave, abhiññāya ime satta dhammā bhāvetabbā”ti.
