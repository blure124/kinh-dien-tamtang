# 7.645–1124. Thắng Tri Tham (4)

TTC 1 —Này các Tỷ-kheo, để thắng tri tham … để hoàn toàn diệt tận … để đoạn tận … để diệt tận … để hoại diệt … để ly tham … để đoạn diệt … để xả bỏ … để từ bỏ … để từ bỏ tham. Bảy pháp này cần phải tu tập.

TTC 2 Ðể thắng tri sân … si … phẫn nộ … hiềm hận … che đậy … não hại … tật đố … xan tham … man trá … lường gạt … ngoan cố … tháo động … mạn … tăng thượng mạn … kiêu, phóng dật … để liễu tri … để hoàn toàn diệt tận … để đoạn tận … để diệt tận … để hoại diệt … để ly tham … để đoạn diệt … để xả bỏ … để từ bỏ … để từ bỏ tham. Bảy pháp này cần phải tu tập.

Thế Tôn thuyết như vậy, các Tỷ-kheo hoan hỷ tín thọ lời Thế Tôn thuyết.
